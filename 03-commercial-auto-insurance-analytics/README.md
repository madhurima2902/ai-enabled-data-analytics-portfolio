# Commercial Auto Insurance Analytics

Portfolio project using fully synthetic and anonymized commercial auto insurance data.

Planned scope:
- 24 months of data
- ~80,000 quotes
- ~32,000 policy terms
- ~40,000 vehicles
- ~6,500 claims
- Premium and performance analysis
- Data-quality profiling and reconciliation
- ~1,200 deliberately seeded duplicate, missing-key, and business-rule exceptions
- Simple agentic AI use case for investigating a flagged data-quality exception category and producing a root-cause/action summary

> All data in this project is synthetic and created for portfolio demonstration purposes. It does not contain customer, insurer, or business-contact data.
