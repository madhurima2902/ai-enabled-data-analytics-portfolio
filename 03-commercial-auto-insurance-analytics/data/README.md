# Synthetic Dataset

The files in this directory are generated by `scripts/generate_synthetic_data.py` using a fixed random seed (`2902`).

The generator creates:

| Dataset | Rows |
|---|---:|
| quotes.csv | 80,000 |
| policies.csv | 32,000 |
| vehicles.csv | 40,000 |
| premiums.csv | 32,000 |
| claims.csv | 6,500 |
| exception_manifest.csv | 1,200 |

The business relationships, reconciliation approach, and exception categories are modeled on the actual commercial-auto analytics work represented by this portfolio project. The published records themselves are synthetic and contain no original client data.

## Seeded exceptions

| Exception | Count |
|---|---:|
| Duplicate quote IDs | 180 |
| Policies with missing quote keys | 140 |
| Vehicles referencing nonexistent policies | 190 |
| Policy/premium written-premium mismatches | 175 |
| Claims referencing nonexistent policies | 135 |
| Invalid policy effective/expiration date relationships | 120 |
| Claims occurring outside valid policy terms | 110 |
| Non-positive written premium | 80 |
| Implausible vehicle model years | 70 |
| **Total** | **1,200** |

The generator independently reruns validation logic before writing the files and fails if the detected exception counts do not equal the seeded counts.

Run from the project directory:

```bash
python scripts/generate_synthetic_data.py
```

This produces the full CSV dataset locally. Large generated CSVs can be kept out of source control while the generator, exception summary, SQL checks, and documentation remain fully reproducible on GitHub.
