# Data

This project uses synthetic banking data generated for learning and portfolio use.

The full generated CSV files are intentionally not duplicated in this mini project. If running the Python profiling script locally, place the relevant source files under:

```text
data/raw/
├── raw_transactions.csv
├── raw_complaints.csv
└── raw_sla_tickets.csv
```

The source-generation work remains in the main Banking Operations Analytics project.
